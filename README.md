# bluepi0j/tap

Homebrew casks for my apps.

```bash
brew tap bluepi0j/tap
brew install --cask margin
```

| Cask | App |
| --- | --- |
| `margin` | [Margin](https://github.com/bluepi0j/margin) — a lightweight Markdown editor for macOS |

Casks here are updated automatically when a new version is released.
